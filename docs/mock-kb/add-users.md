# การเพิ่มหรือลดจำนวนผู้ใช้

> เอกสารสมมติสำหรับทดสอบระบบ

## เพิ่มผู้ใช้
ผู้ดูแลระบบของลูกค้า (Admin) เพิ่มผู้ใช้ได้เองที่เมนู ตั้งค่า > ผู้ใช้ > เพิ่มผู้ใช้
ค่าบริการของผู้ใช้ใหม่คิดตามสัดส่วนวันที่เหลือในรอบบิลนั้น

ถ้าจำนวนผู้ใช้จะเกินขีดจำกัดของแพ็กเกจ (Standard 20 คน, Premium 100 คน)
ต้องอัปเกรดแพ็กเกจก่อน ทีม CS ช่วยส่งคำขออัปเกรดให้ได้ และมีผลภายใน 1 วันทำการ

## ลดผู้ใช้
ลดจำนวนผู้ใช้ได้ แต่มีผลในรอบบิลถัดไปเท่านั้น ไม่มีการคืนเงินสำหรับรอบบิลปัจจุบัน

## Adding users (English summary)
Admins can add users under Settings > Users > Add user. New users are billed pro rata
for the rest of the billing cycle. Reducing users takes effect from the next billing cycle.
